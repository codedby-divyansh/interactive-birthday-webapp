# Happy Birthday Vaaruni 💗

A tiny magical interactive birthday experience built with React, Vite, Framer Motion, and GSAP.

## Quick Start

```bash
npm install
npm run dev
```

Open the URL shown in your terminal (usually `http://localhost:5173`).

## Customize Content

Edit **`src/data/birthdayData.js`** to change all messages, flower content, letter text, and more — no component changes needed.

## Add Background Music

Set a path in `birthdayData.music.src`:

```js
music: {
  enabled: true,
  src: '/your-song.mp3',
},
```

Place the audio file in the `public/` folder. Music only plays after the user interacts (toggle appears top-right).

## Tech Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Lucide React
- Canvas particles
